# GiNuNi 0.7.0-beta.1 — 외화 자막 작업 베타

한국어 SRT가 있는 로컬 영상은 음성 분석 없이 대사와 시간을 불러올 수 있습니다. 자막 파일이 없으면 영상 구간과 내용을 직접 입력해 시작할 수 있습니다.

- SRT 미리보기, 문자 인코딩 선택, 시간차 보정, 겹친 자막 확인 및 합치기
- 밀리초 시간과 여러 줄 대사 유지, 모든 대사 또는 선택한 대사 시간 이동
- 원본 자막 별도 보관, 가져오기 직전 복구본, 편집·검수·출력의 원문 연결 유지
- HWPX·SRT 출력, 이전 프로젝트 원본 백업 후 저장 형식 전환
- 자막 파일 읽기 오류는 가져오기 창 안에 표시하며 기존 대본을 보존

## 이번에 확인한 내용

타입 검사와 프로덕션 빌드, 313개 자동 검사를 통과했습니다. 실제 Electron 화면에서 기존 작업 흐름 8개와 새 자막 작업 흐름 6개를 확인했습니다. 새 흐름에는 공개 Sintel 영상과 공식 한국어 SRT를 이용한 정확한 시간 가져오기, 편집·검수·영상 이동, 시간 보정, 재열기, 실제 HWPX/SRT 출력, 잘못된 인코딩 안내, 시간 없는 첫 행 입력 보호가 포함됩니다.

자료는 실제 영화제 출품작을 대신하는 공개 검증용 샘플입니다. 14분 48초 전체 영상과 한국어 SRT, 90초 연습 자료, 출처 기록은 별도 지원 자료로 제공합니다. 영상과 자막은 저장소나 설치본에 포함하지 않습니다.

## 영상 속 자막 OCR

OCR은 현재 지원 담당자가 로컬에서 추출한 뒤 영상과 대조하여 SRT를 전달하는 시험 절차입니다. 앱 안에서 자동으로 OCR을 실행하거나 외국어를 한국어로 번역하는 기능은 이번 설치본에 포함하지 않습니다.

90초 시험에서 실제 자막 12개를 모두 찾았지만 가짜 자막 4개도 추출했습니다. 정밀도 75%, 매칭된 자막의 공백 제외 문자 오류율 2.03%였습니다. 이 결과는 한 글꼴로 합성한 짧은 표본이며, 실제 영화나 장편의 품질 보증이 아닙니다.

작가 PC에서 설치·재생을 확인하고, 실제 납품 HWPX는 한컴오피스에서 열어 서식과 페이지 나눔을 확인해야 합니다. 이전 버전으로 돌아갈 때는 프로젝트 폴더에 남긴 이전 형식 JSON 백업을 사용하세요. 새 형식 프로젝트를 이전 앱으로 덮어쓰지 마세요.
