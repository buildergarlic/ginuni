# 화면해설 대본 도구 v0.6.0-beta.1

`v0.6.0-beta.1`은 제한된 화면해설작가 파일럿을 먼저 시작하기 위한 베타입니다. 파일럿 배포 승인은 실제 작가 사용성, 실제 한국어 방송 자료의 정확도, 실제 OpenAI 계정 연결, 한컴오피스 긴 문서 검증을 통과했다는 뜻이 아닙니다. 시험용 프로젝트와 백업본으로 먼저 확인하고 중요한 납품에는 사용하지 마세요.

## 주요 변경 사항

- 입력 권리와 외부 전송 동의를 분리하고, 분석 실행·원본 구간·검사 결과를 보존하는 검증 가능한 AI 작업 흐름을 추가했습니다.
- AI 대사 교정은 선택한 대사의 원문·제안·이유를 나란히 보여 주며, 작가가 적용하거나 거절합니다. AI가 화면해설을 생성하거나 행을 자동 승인하지 않습니다.
- 행을 명시적으로 확인 완료하고, 수정하면 다시 확인 전 상태로 돌립니다. 분석 실패·취소·저장 충돌 때 기존 대본을 보존하며 최근 복구본을 제공합니다.
- HWPX/SRT 저장 전에 시간·내용·문서 구조를 검사하고 결과 파일의 SHA-256과 원본 실행 정보를 기록합니다.
- 오른쪽 대사·해설 내용이나 활성 편집창을 클릭하면 로컬 또는 유튜브 영상이 해당 행의 시작 시각으로 이동합니다. 작성 중인 초안은 유지하고, 일시 정지 상태에서는 자동 재생하지 않습니다.
- 검수 화면의 글자 크기 조절과 내용에 맞춘 행 높이 보정을 추가했습니다.

## 파일럿에서 확인할 사항

배포 전 자동 검증에서는 테스트 222개, 타입 검사·빌드, 실제 Electron 작업 흐름 8개, 유튜브 메시지 경계 점검 4개, 실제 공개 유튜브 영상의 클릭 이동 점검 4개가 통과했습니다. 실제 영상 점검에는 공개 IFrame API 예제만 사용했으며, 실제 방송 자료의 정확도나 작가 사용성 승인을 뜻하지 않습니다.

- 허가된 실제 한국어 방송 자료에서 대사 경계, 다화자·동시 발화·음악·무음 구간을 사람이 확인합니다.
- 화면해설작가 5–8명이 첫 사용, 오류 복구, 검수, HWPX/SRT 납품 동선을 수행합니다.
- 오른쪽 대사와 해설, 활성 편집창을 각각 눌러 로컬·유튜브 영상이 정확한 시작 시각으로 이동하고 초안·일시 정지 상태가 유지되는지 확인합니다.
- 실제 OpenAI 계정의 유료 전사·교정 연결과 한컴오피스의 긴 문서 페이지 나눔·서식을 확인합니다.
- 기존 `v0.5.0-beta.7` 설치본이 새 베타를 찾고 다운로드하며, 설치 뒤 프로젝트와 설정이 보존되는지 확인합니다.

## 설치 및 보안 안내

기존 프로젝트의 대사와 해설은 유지합니다. 과거 버전에서 편집만 해도 설정되던 확인 표시는 새 워크플로우에서 **확인 전**으로 이관되므로, 작가가 내용을 확인한 뒤 다시 확인 완료로 표시해 주세요.

호환되는 XML·YAML 등 라이브러리 보안 수정 버전을 반영했고, 점검 시점의 설치 앱 의존성 검사(`npm audit --omit=dev`)는 경고 0건입니다. 개발용 Vitest 계열의 중간 위험도 경고 2건은 별도 메이저 버전 전환 검증 대상으로 남겨 두었으며 배포 앱에는 포함되지 않습니다.

공식 설치 파일과 `SHA256SUMS.txt`는 [GiNuNi Releases](https://github.com/buildergarlic/ginuni/releases)에서 확인하세요. 태그를 푸시한 뒤 GitHub Actions의 Windows release가 성공하기 전에는 새 설치 파일이 제공되지 않습니다.

현재 빌드 설정은 코드 서명 인증서 두 값이 모두 없으면 설치 프로그램과 앱이 실제로 서명되지 않았는지 검사한 뒤 무서명 베타로 게시합니다. 최종 릴리스의 실제 서명 상태는 GitHub Actions 결과에서 확인해야 합니다. 무서명인 경우 Windows SmartScreen에 알 수 없는 게시자 경고가 나타날 수 있으므로 공식 출처와 SHA-256을 확인하세요.
