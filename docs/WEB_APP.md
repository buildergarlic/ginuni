# 기누니 웹 작업실

Windows 설치형과 별도로 브라우저에서 영상·자막을 검수하고 화면해설 대본을 작성합니다. 로그인, 설치 파일, API 키 없이 사용할 수 있습니다.

**공개 서비스:** [기누니 웹 작업실](https://buildergarlic.github.io/ginuni/). 아래는 현재 소스의 기능 안내입니다. 2026년 9월 19일 먼저 배포한 긴 영상 분할 기능의 검증 기록과 이후 추가한 실제 대화 샘플·비교 기능의 검증은 구분합니다. 심사 기간인 **2026년 9월 21일~10월 17일** 동안 저장소와 GitHub Pages를 공개 상태로 유지하세요. 정적 사이트에는 자동 종료 시각을 설정하지 않았습니다.

## 바로 사용하기

1. **샘플로 바로 체험하기**를 누르면 실제 유성영화 **Shy Guy (1947)**의 60초와 이 영상으로 미리 실행한 AI 대사 초안을 엽니다. 원본 01:10–02:10의 아버지와 아들 대화이며 실제 영어 음성을 보존했습니다. 합성 음성이나 가상 대사가 아닙니다. [출처·권리·변환 내역](SAMPLE_MEDIA.md)을 확인할 수 있고, **샘플 음성 AI 다시 분석**으로 현재 브라우저에서 직접 모델을 실행할 수 있습니다.
2. **내 영상으로 시작 → 작업 도구**에서 자료 사용 권한을 확인하고 영상·음성을 선택합니다. SRT가 있으면 **SRT 불러오기**를 사용하고 필요한 시간차를 초 단위로 입력합니다. **대사 +**, **해설 +**로 직접 작성할 수도 있습니다.
3. 자막이 없으면 **음성 언어**에서 원문의 언어를 선택하고 **AI로 대사 만들기**를 누릅니다. 한국어는 아래의 **한국어 분석 품질**도 선택할 수 있습니다. 한국어와 아래의 9개 외국어를 지원하고, 샘플은 영어로 고정됩니다. 선택한 원어로 전사하며 최대 3시간의 파일을 60초 구간으로 나누어 차례로 분석합니다. 첫 실행에는 모델을 내려받으므로 인터넷 연결과 시간이 필요하며, 긴 영상은 분석에도 오래 걸릴 수 있습니다. 분석하는 동안 창을 열어 두세요. 취소하거나 실패하면 기존 대본을 유지합니다.
4. 영상에는 현재 대사 행을 반영한 자막이 표시됩니다. 행을 눌러 해당 시점으로 이동하거나 **이 구간 듣기**로 선택한 시작·종료 구간을 재생하며 내용과 시간을 수정합니다. **확인 완료 · 다음**으로 검수하고 **해설 후보 채우기**로 대사 사이의 빈 시간 구간을 찾습니다. 후보 구간에도 음악·효과음이 있을 수 있으므로 영상을 직접 확인하세요.
5. 샘플의 **참고 자막과 대사·시간 비교**를 펼치면 Internet Archive의 미검수 자동 자막 13행을 볼 수 있습니다. 각 참고 구간을 재생하고 AI 초안과 원음을 대조하세요. 단어 차이와 비교 가능한 구간의 시작·끝 시간차는 검토를 돕는 수치이며, 정답 여부나 AI 정확도 점수가 아닙니다.
6. **대본 내보내기**에서 대사와 해설을 포함한 **HWPX 한글 대본**, 대사만 포함한 **SRT 자막**, 계속 편집할 **JSON 작업 백업**을 내려받습니다. 실제 대화 샘플의 대사도 SRT로 내보낼 수 있습니다.

## 한국어 음성 분석 품질 선택

**작업 도구 → 음성 언어 → 한국어**에서 분석 품질을 고릅니다. 파일의 언어 메타데이터나 자동 언어 감지에 맡기지 않고, 선택한 한국어를 모델에 명시해 원어로 받아씁니다.

| 선택 | 실행 방식 | 처음 내려받는 음성 모델 |
| --- | --- | --- |
| 자동 | 지원 GPU가 있으면 정밀, 없으면 CPU 호환 모델 선택 | 선택된 모델 한 종류 |
| 정밀 | Whisper large-v3-turbo, WebGPU, encoder fp16 / decoder q4 | 약 1.62GB |
| 호환 | Whisper small, CPU·WASM, q8 | 약 255MB |

정밀 분석에는 WebGPU의 fp16 연산과 필요한 버퍼 크기를 지원하는 GPU가 필요합니다. 최신 Chrome·Edge에서 그래픽 가속을 켜고 사용하세요. GPU가 없거나 지원 조건을 충족하지 않으면 **자동**은 호환 모델을 선택하고, **정밀**을 직접 선택했으면 호환 모드 안내를 표시합니다. GPU 지원 여부와 실제 여유 메모리는 다르므로, 모델 로딩·분석 중 자원이 부족하면 다른 탭을 닫거나 **호환**으로 바꾸어 다시 실행하세요. 다운로드 용량은 실행 메모리 사용량이 아니며 GPU·브라우저에는 추가 메모리가 필요합니다. 큰 모델은 PC에서 사용하는 것을 권장합니다.

한국어는 먼저 Silero VAD로 발화 구간을 찾고, 말 앞뒤의 짧은 문맥을 함께 분석합니다. 음악·효과음만 있는 부분에서 생기는 대사 오인식을 줄이기 위한 절차이며, 작은 목소리를 놓치거나 음악을 말소리로 판단할 수도 있습니다. 말소리가 검출되지 않은 구간에는 대사를 만들지 않으므로 누락 여부도 영상을 재생하며 확인하세요.

긴 글자 반복이나 출력 길이 한도로 인한 문장 잘림이 의심되면 해당 음성 조각을 더 짧게 나누어 한 차례 재분석합니다. 재분석에만 6개 토큰의 반복 생성 제한을 적용합니다. 최초 분석에는 이 제한을 적용하지 않아 실제 반복 발화를 보존하며, 제한으로 바뀐 문장이 정확하다고 간주하지 않습니다. 정상으로 판단한 기존 대사는 유지하고, 재분석 결과를 적용한 행에도 **음성 확인 필요** 표시를 남깁니다. **첫 확인 필요 대사로 → 이 구간 듣기**에서 내용과 시간을 확인하고 수정한 뒤 **확인 완료 · 다음**으로 진행하세요. 교체된 행은 **재분석 전 인식 결과 보기**로 첫 결과도 확인할 수 있습니다. 반복처럼 보이는 실제 발화를 자동으로 정답·오답으로 판단하는 기능은 아닙니다.

큰 모델과 발화 검출을 사용해도 사투리의 낱말·어미, 고유명사, 배경음, 겹친 대사, 발화 시작·끝의 오류가 남을 수 있습니다. 경고가 없는 행도 검수해야 합니다. 아래의 과거 실행 기록은 당시 모델·기기의 기능 검사이며, 이번 한국어 모델 변경의 정확도나 사투리 개선율을 뜻하지 않습니다.

## 외국어 대사를 한국어로 번역하기

**한국어로 대사 읽기**에서 원문 언어를 고르고 **한국어로 번역**을 누릅니다. 영어·일본어·중국어·스페인어·프랑스어·독일어·이탈리아어·포르투갈어·러시아어를 지원합니다. 음성으로 받아쓴 대사뿐 아니라 SRT로 가져오거나 직접 입력한 대사도 번역할 수 있으며, 영상 파일을 다시 연결할 필요는 없습니다. 한국어 해설 행은 번역 대상에서 제외합니다.

원문과 타임스탬프는 그대로 보존하고 한국어 초안을 별도로 저장합니다. **원문 보기 / 한국어 보기**로 편집 언어를 바꾸며, 한국어 행 아래에는 원문도 표시합니다. 영상 자막과 SRT·HWPX는 현재 선택한 언어를 사용하고 JSON 백업에는 양쪽 내용·한국어 초안·각 언어의 검수 상태를 함께 저장합니다. 한국어 파일명에는 `_한국어`를 붙입니다. **처음 번역으로 복원**과 **되돌리기**도 사용할 수 있습니다.

원문을 바꾼 행은 기존 번역이 오래됐음을 표시하고, 미번역 행과 함께 한국어 내보내기를 막습니다. 다시 번역하거나 원문 보기로 전환해 내보내세요. 번역 수정과 검수는 원문의 검수 상태에 영향을 주지 않습니다. 시간·화자·행 구분을 바꾸면 양쪽을 다시 확인하도록 처리합니다. 음성을 다시 분석하거나 새 SRT를 적용하면 새 원문으로 시작하며 이전 번역을 새 행에 붙이지 않습니다.

번역은 무료이며 API 키 없이 브라우저 Web Worker·WASM에서 실행됩니다. 첫 사용에는 **약 640MB**의 공개 모델 파일이 필요하므로 **PC의 최신 Chrome·Edge**를 권장합니다. 다운로드 용량과 실행 메모리는 서로 다르며, 모델 실행에는 수 GB의 여유 메모리가 필요할 수 있습니다. 실제 기기의 여유 메모리·연결 속도·대사 수에 따라 시간이 달라집니다. 취소·실패 시 부분 결과를 적용하지 않고 원문과 기존 번역을 유지합니다.

긴 행은 문장과 모델 토큰 제한에 맞춰 순서대로 번역한 후 같은 행으로 합칩니다. 행의 시간은 바꾸지 않습니다. 전문어, 말투, 문맥, 원문 인식 오류가 번역에 영향을 주므로 결과는 미검수 초안으로 표시합니다. 작은 로컬 모델의 번역을 완성된 납품 자막으로 간주하지 마세요.

## 지원 범위와 저장

| 항목 | 웹 작업실의 범위 |
| --- | --- |
| 영상 재생·자막·직접 편집 | 최대 3시간, 최대 20,000개 대본 행, 행당 10,000자 |
| 브라우저 AI 음성 분석 | 한국어 Whisper large-v3-turbo 또는 small / 영어 base.en / 그 외 지원 언어 tiny, 전체 길이 최대 3시간, 60초씩 순차 분석 |
| 한국어 대사 번역 | 9개 외국어 → 한국어, M2M100 q8, 원문·시간 보존, 행별 10,000자 이내, 긴 입력 자동 분할 |
| 영상 자막·구간 재생 | 현재 대사 행을 WebVTT 자막으로 표시, 선택 행과 샘플 참고 자막의 시작·종료 구간 듣기 |
| 지원 코덱의 구간별 읽기 | MediaBunny·WebCodecs 사용, 고정 100MB 파일 제한 없음 |
| 호환성 대체 분석 | 구간별 읽기가 불가능할 때만 사용, 5분·100MB 이하 파일로 제한 |
| 파일 형식 | 브라우저가 재생·오디오 해독할 수 있는 MP4, WebM, MP3, WAV 등 |
| SRT 가져오기 | 5MB 이하, UTF-8 또는 BOM이 있는 UTF-16. 겹친 자막·잘못된 시간은 오류로 알리며 기존 대본을 유지 |
| JSON 백업 가져오기 | 기누니 **웹** 백업, 20MB 이하. 원본 작업을 덮어쓰지 않고 새 작업으로 복원 |
| 브라우저 저장 | 현재 사이트·브라우저에 최대 10개. 용량 부족이나 저장 실패를 표시하며 기존 작업을 자동 삭제하지 않음 |

MP4 확장자여도 내부 코덱에 따라 실패할 수 있습니다. 재생 문제가 있으면 MP4(H.264/AAC), 음성 분석 문제가 있으면 WAV·MP3 또는 AAC 오디오가 포함된 MP4로 변환하세요. 긴 파일의 구간별 읽기가 지원되지 않으면 변환 안내를 표시하며 파일 전체를 메모리로 읽는 대체 분석을 실행하지 않습니다. 파일 용량 제한이 없어도 모든 코덱이나 임의의 크기 파일에 대한 성공을 보장하지 않습니다. 모바일에서도 편집 화면을 사용할 수 있지만 AI 실행 속도·메모리·다운로드 동작은 기기와 브라우저에 따라 다릅니다. Chrome·Edge의 최신 버전을 우선 사용하세요.

AI는 대사와 타임코드의 초안을 만듭니다. 모델 크기와 관계없이 사투리·고유명사·발음·배경음에 인식 오류가 생기거나 발화 시작·끝이 어긋날 수 있습니다. 화면 묘사 자동 생성, 자동 화자 분리, 유튜브 주소 입력, OpenAI API 연결은 웹 버전에 포함하지 않습니다.

원본 영상·음성은 서버에 업로드하거나 브라우저 저장소에 보관하지 않습니다. 새로고침하거나 작업을 다시 열면 같은 원본 파일을 다시 선택하세요. 대본과 파일 이름은 브라우저에 저장되며, 브라우저 데이터 삭제·시크릿 모드 종료·기기 변경 시 복원되지 않을 수 있습니다. 중요한 작업은 JSON 백업을 별도 보관하세요. 웹 JSON과 설치형 프로젝트는 구조가 다르며 자동 변환·동기화를 지원하지 않습니다. 대사 교환에는 SRT, 완성 대본 전달에는 HWPX를 사용할 수 있습니다.

앱에 포함한 공개 영화 샘플은 다시 파일을 선택하지 않아도 재생됩니다. 미리 준비한 AI 초안은 샘플을 열 때마다 새로 추론한 결과가 아니며, 사용자가 재분석 버튼을 누르면 그때 모델이 실행됩니다. 이전 버전에서 저장한 45초 가상 장면이나 1906년 무성 기록영화의 대본은 그대로 편집할 수 있지만, 내용이 다른 새 영화가 자동으로 연결되지는 않습니다. 현재 대화 샘플은 홈에서 새로 여세요.

Archive 참고 자막도 자동 인식 결과여서 틀린 단어와 문장 구분을 포함합니다. 원문의 오인식을 임의로 고치지 않고 발췌 구간에 맞게 시간만 조정했습니다. 비교 화면은 단어의 대치·누락·추가를 세고, 문장 내용과 양끝이 대응하는 구간에 한해 시간차를 보여 줍니다. 단어가 다르거나 여러 행에 걸쳐 대응이 불명확하면 원음을 듣고 판단해야 합니다. 이 참고 자료를 정답으로 삼아 정확도를 주장하지 않습니다.

## AI 모델과 네트워크

AI는 `@huggingface/transformers` 3.8.1과 다음 고정 리비전의 모델을 사용합니다. Web Worker에서 WebGPU 또는 WebAssembly로 기기 안에서 실행하며 API 사용료가 없습니다. 모델·실행 파일 다운로드에는 데이터 사용량이 발생합니다.

| 용도 | 모델 | 고정 리비전 |
| --- | --- | --- |
| 한국어 정밀 · encoder fp16 / decoder q4 | `onnx-community/whisper-large-v3-turbo` | `360ebcde2559d60bb474678be3c1de9ef347d01a` |
| 한국어 호환 · q8 | `Xenova/whisper-small` | `2d67713f236afa48a18992566e7647f6ca848e13` |
| 한국어·영어를 제외한 지원 언어의 음성 · q8 | `Xenova/whisper-tiny` | `5332fcc35e32a33b86612b9a57a89be7906102b1` |
| 영어 및 Shy Guy 샘플 | `Xenova/whisper-base.en` | `95bf40a508535962c6483ead40270b2e32267508` |
| 외국어 대사의 한국어 번역 | `Xenova/m2m100_418M` | `9c374f0b7aca709787cea97b047bfbbd1559d177` |

한국어 발화 검출에는 `snakers4/silero-vad`의 고정 커밋 `60b7ffa243625ebdc1070275a29f18c87843786a`에 있는 ONNX 모델을 사용합니다. 약 2.3MB 파일을 웹 정적 자원에 포함하고 같은 사이트에서 불러옵니다. Whisper와 같은 버전의 ONNX Runtime Web을 사용하며, 발화 검출도 음성 업로드 없이 기기에서 실행합니다.

긴 파일은 `mediabunny` 1.58.1로 필요한 구간만 읽어 처리합니다. 기본 구간은 60초이며 경계의 말을 인식할 수 있도록 앞뒤 최대 2초를 함께 읽습니다. 결과 시간은 원본 영상 기준으로 되돌리고 겹친 문맥의 중복을 정리합니다. 파일 읽기 캐시는 8MiB로 제한하며, 추론에 전달하는 한 구간의 16kHz 모노 음성 배열은 최대 64초·약 4.1MB입니다. 이는 앱 전체의 메모리 사용량을 뜻하지 않습니다. 모델, 디코더, 원본 채널 버퍼, 브라우저 실행에는 별도 메모리가 필요합니다. 짧은 파일의 호환성 대체 분석은 원본 전체를 해독하므로 5분·100MB 제한을 유지합니다.

각 구간 안에서 긴 디지털 무음을 분리합니다. 한국어는 여기에 발화 검출을 적용하고, 검출한 말 앞뒤에 최대 320ms 문맥을 남겨 가까운 발화를 묶습니다. 한 음성 조각은 최대 28초이며 긴 발화의 분할 경계에는 640ms 문맥을 겹칩니다. 짧다는 이유만으로 검출한 발화를 버리지는 않습니다. 강한 반복·문장 잘림이 의심되면 13초 단위에 앞뒤 최대 1초 문맥을 추가해 한 차례 재분석합니다. 이러한 처리와 경고는 오류 검토를 돕지만 모든 누락·오인식을 찾거나 고치지는 못합니다.

영어 분석에서 소리가 있는 조각의 처음 8초 이상이 누락되면, 시작점을 2초 옮겨 누락된 앞부분만 한 번 더 분석합니다. 기존에 인식한 문장과 시간을 유지하고 그 이전에 끝나는 복구 결과만 합칩니다. 같은 모델과 음성 버퍼를 재사용하며 모든 누락을 찾아내는 기능은 아닙니다.

처음 사용할 때 Hugging Face 및 관련 다운로드 CDN에서 Whisper·번역 모델을, jsDelivr에서 WASM 실행 파일을 가져옵니다. Silero VAD는 사이트에 포함된 정적 모델 파일을 사용합니다. 브라우저가 허용하면 모델을 캐시하지만 저장 공간 정책이나 캐시 삭제로 다시 다운로드할 수 있습니다. 사이트 글꼴은 Google Fonts에서 가져옵니다. 따라서 미디어를 외부로 보내지 않아도 이러한 정적 자원 요청은 발생하며, 완전한 오프라인 실행을 보장하지 않습니다. 자세한 라이선스는 [제3자 구성 요소 고지](../THIRD_PARTY_NOTICES.md)를 참고하세요.

## 개발과 배포

Node.js 24 환경에서 저장소 루트 기준으로 실행합니다.

```powershell
npm ci
npm run dev:web
```

개발 주소는 `http://127.0.0.1:5174/`입니다. 설치형은 기존 `npm run dev`를 그대로 사용합니다. 웹 빌드와 확인은 다음과 같습니다.

```powershell
npm run verify
npm run preview:web
```

`verify`는 타입 검사·테스트·설치형 빌드·웹 빌드를 실행합니다. 웹 결과물은 `dist-web/`, 미리보기 주소는 `http://127.0.0.1:4174/`입니다. 정적 호스팅에 `dist-web/` 내용을 게시하면 되며 추론 서버나 비밀 키가 필요하지 않습니다. 하위 경로에 게시할 경우 빌드 전에 경로를 지정합니다.

```powershell
$env:GINUNI_WEB_BASE = '/ginuni/'
npm run build:web
Remove-Item Env:GINUNI_WEB_BASE
```

[웹 배포 워크플로](../.github/workflows/web.yml)는 `main`의 관련 파일 변경이나 수동 실행으로 테스트·웹 빌드 후 GitHub Pages에 게시합니다. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다. 워크플로 성공만으로 제출을 마치지 말고 공개 URL에서 샘플 편집·다운로드·모델 로딩을 확인하세요. 설치형 릴리스는 기존 `v*` 태그 워크플로로 별도 배포합니다.
