# 기누니 웹 작업실

Windows 설치형과 별도로 브라우저에서 영상·자막을 검수하고 화면해설 대본을 작성합니다. 로그인, 설치 파일, API 키 없이 사용할 수 있습니다.

**공개 서비스:** [기누니 웹 작업실](https://buildergarlic.github.io/ginuni/). 2026년 9월 19일 공개 배포, HTTP 200 응답, 로그인 없는 실제 브라우저 편집·파일 내보내기를 확인했습니다. 심사 기간인 **2026년 9월 21일~10월 17일** 동안 저장소와 GitHub Pages를 공개 상태로 유지하세요. 정적 사이트에는 자동 종료 시각을 설정하지 않았습니다.

## 바로 사용하기

1. **샘플로 바로 체험하기**를 누르면 공원에서 친구와 걷는 45초 예시 대본을 엽니다. 재생에 따라 움직이는 직접 만든 장면 카드이며 촬영 영상·녹음 음성·실제 AI 분석 결과가 아닙니다.
2. **내 영상으로 시작 → 작업 도구**에서 자료 사용 권한을 확인하고 영상·음성을 선택합니다. SRT가 있으면 **SRT 불러오기**를 사용하고 필요한 시간차를 초 단위로 입력합니다. **대사 +**, **해설 +**로 직접 작성할 수도 있습니다.
3. 자막이 없으면 **AI로 대사 만들기**를 누릅니다. 첫 실행에는 모델을 내려받으므로 인터넷 연결과 시간이 필요합니다. 분석을 취소하거나 실패하면 기존 대본을 유지합니다.
4. 행을 눌러 해당 시점으로 이동하고 내용·구분·시작·종료를 수정합니다. **확인 완료 · 다음**으로 검수하며, **해설 후보 채우기**로 대사 사이의 빈 시간 구간을 찾습니다. 후보 구간에도 음악·효과음이 있을 수 있으므로 영상을 직접 확인하세요.
5. **대본 내보내기**에서 대사와 해설을 포함한 **HWPX 한글 대본**, 대사만 포함한 **SRT 자막**, 계속 편집할 **JSON 작업 백업**을 내려받습니다.

## 지원 범위와 저장

| 항목 | 웹 작업실의 범위 |
| --- | --- |
| 영상 재생·자막·직접 편집 | 최대 3시간, 최대 20,000개 대본 행, 행당 10,000자 |
| 브라우저 AI 음성 분석 | 한국어, 최대 5분·100MB, Whisper tiny 양자화 모델 |
| 파일 형식 | 브라우저가 재생·오디오 해독할 수 있는 MP4, WebM, MP3, WAV 등 |
| SRT 가져오기 | 5MB 이하, UTF-8 또는 BOM이 있는 UTF-16. 겹친 자막·잘못된 시간은 오류로 알리며 기존 대본을 유지 |
| JSON 백업 가져오기 | 기누니 **웹** 백업, 20MB 이하. 원본 작업을 덮어쓰지 않고 새 작업으로 복원 |
| 브라우저 저장 | 현재 사이트·브라우저에 최대 10개. 용량 부족이나 저장 실패를 표시하며 기존 작업을 자동 삭제하지 않음 |

MP4 확장자여도 내부 코덱에 따라 실패할 수 있습니다. 재생 문제가 있으면 MP4(H.264/AAC), 음성 분석 문제가 있으면 WAV·MP3 또는 AAC 오디오가 포함된 MP4로 변환하세요. 짧은 파일로 먼저 확인하는 것이 좋습니다. 모바일에서도 편집 화면을 사용할 수 있지만 AI 실행 속도·메모리·다운로드 동작은 기기와 브라우저에 따라 다릅니다. Chrome·Edge의 최신 버전을 우선 사용하세요.

AI는 대사와 타임코드의 초안을 만듭니다. 작은 모델이므로 한국어 고유명사·발음·배경음에 인식 오류가 생길 수 있습니다. 화면 묘사 자동 생성, 자동 화자 분리, 유튜브 주소 입력, OpenAI API 연결은 웹 버전에 포함하지 않습니다.

원본 영상·음성은 서버에 업로드하거나 브라우저 저장소에 보관하지 않습니다. 새로고침하거나 작업을 다시 열면 같은 원본 파일을 다시 선택하세요. 대본과 파일 이름은 브라우저에 저장되며, 브라우저 데이터 삭제·시크릿 모드 종료·기기 변경 시 복원되지 않을 수 있습니다. 중요한 작업은 JSON 백업을 별도 보관하세요. 웹 JSON과 설치형 프로젝트는 구조가 다르며 자동 변환·동기화를 지원하지 않습니다. 대사 교환에는 SRT, 완성 대본 전달에는 HWPX를 사용할 수 있습니다.

## AI 모델과 네트워크

AI는 `@huggingface/transformers` 3.8.1과 `Xenova/whisper-tiny`의 고정 리비전 `5332fcc35e32a33b86612b9a57a89be7906102b1`을 사용합니다. Web Worker에서 WebAssembly로 실행하며 API 사용료가 없습니다. 모델·실행 파일 다운로드에는 데이터 사용량이 발생합니다.

처음 사용할 때 Hugging Face 및 관련 다운로드 CDN에서 모델을, jsDelivr에서 WASM 실행 파일을 가져옵니다. 브라우저가 허용하면 모델을 캐시하지만 저장 공간 정책이나 캐시 삭제로 다시 다운로드할 수 있습니다. 사이트 글꼴은 Google Fonts에서 가져옵니다. 따라서 미디어를 외부로 보내지 않아도 이러한 정적 자원 요청은 발생하며, 완전한 오프라인 실행을 보장하지 않습니다. 자세한 라이선스는 [제3자 구성 요소 고지](../THIRD_PARTY_NOTICES.md)를 참고하세요.

## 개발과 배포

Node.js 24 환경에서 저장소 루트 기준으로 실행합니다.

```powershell
npm ci
npm run dev:web
```

개발 주소는 `http://127.0.0.1:5174/`입니다. 설치형은 기존 `npm run dev`를 그대로 사용합니다. 웹 빌드와 확인은 다음과 같습니다.

```powershell
npm run verify
npm run preview:web
```

`verify`는 타입 검사·테스트·설치형 빌드·웹 빌드를 실행합니다. 웹 결과물은 `dist-web/`, 미리보기 주소는 `http://127.0.0.1:4174/`입니다. 정적 호스팅에 `dist-web/` 내용을 게시하면 되며 추론 서버나 비밀 키가 필요하지 않습니다. 하위 경로에 게시할 경우 빌드 전에 경로를 지정합니다.

```powershell
$env:GINUNI_WEB_BASE = '/ginuni/'
npm run build:web
Remove-Item Env:GINUNI_WEB_BASE
```

[웹 배포 워크플로](../.github/workflows/web.yml)는 `main`의 관련 파일 변경이나 수동 실행으로 테스트·웹 빌드 후 GitHub Pages에 게시합니다. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다. 워크플로 성공만으로 제출을 마치지 말고 공개 URL에서 샘플 편집·다운로드·모델 로딩을 확인하세요. 설치형 릴리스는 기존 `v*` 태그 워크플로로 별도 배포합니다.

## 검증

`npm run verify` 외에 실제 브라우저 흐름은 `scripts/qa-web.mjs`로 확인합니다. 먼저 `npm run preview:web`를 실행하고, 별도 터미널에서 설치된 Playwright 모듈의 절대 경로를 지정합니다. 기본 브라우저는 Microsoft Edge이며 기존 사용자 프로필을 사용하지 않습니다.

```powershell
$env:GINUNI_PLAYWRIGHT_MODULE = 'C:\path\to\node_modules\playwright\index.mjs'
node scripts/qa-web.mjs
```

Playwright가 현재 프로젝트에서 해석되면 환경 변수를 생략할 수 있습니다. `GINUNI_BROWSER_CHANNEL=chrome`으로 Chrome을 선택하고, `GINUNI_WEB_URL`로 다른 미리보기 주소를 지정할 수 있습니다. 검증 결과와 스크린샷은 Git에서 제외된 `output/playwright/`에 저장합니다.

이 검증은 샘플 편집·검수·포커스, HWPX/SRT/JSON 실제 다운로드, 새로고침 후 복원, JSON 새 작업 복원, 미디어 교체 후 되돌리기, 잘못된 SRT의 기존 대본 보존, 390px 모바일 화면을 확인합니다. AI 품질을 평가하는 테스트는 아닙니다.

2026년 9월 19일 로컬과 공개 URL 양쪽에서 위 브라우저 검증을 통과했습니다. 별도 Edge 프로필에서 공개 URL에 한국어 WAV(388KB)를 선택해 실제 모델 다운로드와 전사를 실행했고, 약 13.7초에 타임코드가 있는 대사 3행을 얻었습니다. 네트워크 요청 45건은 모두 GET이었고 음성 업로드, HTTP 오류, 실행 오류는 없었습니다. 작은 모델의 한국어 전사 오류도 확인했으므로 작가의 내용·시간 검수가 필요합니다. 이 확인은 모든 코덱·기기의 지원이나 납품 품질을 보장하는 평가는 아닙니다.
