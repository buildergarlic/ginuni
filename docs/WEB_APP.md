# 기누니 웹 작업실

Windows 설치형과 별도로 브라우저에서 영상·자막을 검수하고 화면해설 대본을 작성합니다. 로그인, 설치 파일, API 키 없이 사용할 수 있습니다.

**공개 서비스:** [기누니 웹 작업실](https://buildergarlic.github.io/ginuni/). 2026년 9월 19일 첫 웹 버전의 공개 배포, HTTP 200 응답, 로그인 없는 실제 브라우저 편집·파일 내보내기를 확인했습니다. 아래 실제 영화 샘플과 긴 영상 분할 분석 변경은 추가 검증 중이며, 첫 버전의 검증 결과를 이 변경의 검증 결과로 간주하지 않습니다. 심사 기간인 **2026년 9월 21일~10월 17일** 동안 저장소와 GitHub Pages를 공개 상태로 유지하세요. 정적 사이트에는 자동 종료 시각을 설정하지 않았습니다.

## 바로 사용하기

1. **샘플로 바로 체험하기**를 누르면 1906년 샌프란시스코의 실제 기록영화 60초와 편집용 해설 초안 6행을 엽니다. 자동차·마차·전차가 오가는 실제 장면을 보며 해설을 고칠 수 있습니다. 공개 영화의 발췌본이며 [출처·권리·변환 내역](SAMPLE_MEDIA.md)을 제공합니다. 무성 영화이므로 소리나 대사 행이 없으며, 음성 AI 분석 예시로 사용하지 않습니다.
2. **내 영상으로 시작 → 작업 도구**에서 자료 사용 권한을 확인하고 영상·음성을 선택합니다. SRT가 있으면 **SRT 불러오기**를 사용하고 필요한 시간차를 초 단위로 입력합니다. **대사 +**, **해설 +**로 직접 작성할 수도 있습니다.
3. 자막이 없으면 **AI로 대사 만들기**를 누릅니다. 최대 3시간의 파일을 60초 구간으로 나누어 차례로 분석합니다. 첫 실행에는 모델을 내려받으므로 인터넷 연결과 시간이 필요하며, 긴 영상은 분석에도 오래 걸릴 수 있습니다. 분석하는 동안 창을 열어 두세요. 취소하거나 실패하면 기존 대본을 유지합니다.
4. 행을 눌러 해당 시점으로 이동하고 내용·구분·시작·종료를 수정합니다. **확인 완료 · 다음**으로 검수하며, **해설 후보 채우기**로 대사 사이의 빈 시간 구간을 찾습니다. 후보 구간에도 음악·효과음이 있을 수 있으므로 영상을 직접 확인하세요.
5. **대본 내보내기**에서 대사와 해설을 포함한 **HWPX 한글 대본**, 대사만 포함한 **SRT 자막**, 계속 편집할 **JSON 작업 백업**을 내려받습니다.

## 지원 범위와 저장

| 항목 | 웹 작업실의 범위 |
| --- | --- |
| 영상 재생·자막·직접 편집 | 최대 3시간, 최대 20,000개 대본 행, 행당 10,000자 |
| 브라우저 AI 음성 분석 | 한국어, 전체 길이 최대 3시간, 60초씩 순차 분석, Whisper tiny 양자화 모델 |
| 지원 코덱의 구간별 읽기 | MediaBunny·WebCodecs 사용, 고정 100MB 파일 제한 없음 |
| 호환성 대체 분석 | 구간별 읽기가 불가능할 때만 사용, 5분·100MB 이하 파일로 제한 |
| 파일 형식 | 브라우저가 재생·오디오 해독할 수 있는 MP4, WebM, MP3, WAV 등 |
| SRT 가져오기 | 5MB 이하, UTF-8 또는 BOM이 있는 UTF-16. 겹친 자막·잘못된 시간은 오류로 알리며 기존 대본을 유지 |
| JSON 백업 가져오기 | 기누니 **웹** 백업, 20MB 이하. 원본 작업을 덮어쓰지 않고 새 작업으로 복원 |
| 브라우저 저장 | 현재 사이트·브라우저에 최대 10개. 용량 부족이나 저장 실패를 표시하며 기존 작업을 자동 삭제하지 않음 |

MP4 확장자여도 내부 코덱에 따라 실패할 수 있습니다. 재생 문제가 있으면 MP4(H.264/AAC), 음성 분석 문제가 있으면 WAV·MP3 또는 AAC 오디오가 포함된 MP4로 변환하세요. 긴 파일의 구간별 읽기가 지원되지 않으면 변환 안내를 표시하며 파일 전체를 메모리로 읽는 대체 분석을 실행하지 않습니다. 파일 용량 제한이 없어도 모든 코덱이나 임의의 크기 파일에 대한 성공을 보장하지 않습니다. 모바일에서도 편집 화면을 사용할 수 있지만 AI 실행 속도·메모리·다운로드 동작은 기기와 브라우저에 따라 다릅니다. Chrome·Edge의 최신 버전을 우선 사용하세요.

AI는 대사와 타임코드의 초안을 만듭니다. 작은 모델이므로 한국어 고유명사·발음·배경음에 인식 오류가 생길 수 있습니다. 화면 묘사 자동 생성, 자동 화자 분리, 유튜브 주소 입력, OpenAI API 연결은 웹 버전에 포함하지 않습니다.

원본 영상·음성은 서버에 업로드하거나 브라우저 저장소에 보관하지 않습니다. 새로고침하거나 작업을 다시 열면 같은 원본 파일을 다시 선택하세요. 대본과 파일 이름은 브라우저에 저장되며, 브라우저 데이터 삭제·시크릿 모드 종료·기기 변경 시 복원되지 않을 수 있습니다. 중요한 작업은 JSON 백업을 별도 보관하세요. 웹 JSON과 설치형 프로젝트는 구조가 다르며 자동 변환·동기화를 지원하지 않습니다. 대사 교환에는 SRT, 완성 대본 전달에는 HWPX를 사용할 수 있습니다.

앱에 포함한 공개 영화 샘플은 다시 파일을 선택하지 않아도 재생됩니다. 이전 버전에서 저장한 45초 가상 장면 샘플은 기존 대본 그대로 편집할 수 있지만, 내용이 다른 새 영화가 자동으로 연결되지는 않습니다. 실제 영화를 보려면 홈에서 새 샘플을 여세요. 새 샘플은 해설만 있으므로 SRT 대신 HWPX 또는 JSON으로 내보냅니다.

## AI 모델과 네트워크

AI는 `@huggingface/transformers` 3.8.1과 `Xenova/whisper-tiny`의 고정 리비전 `5332fcc35e32a33b86612b9a57a89be7906102b1`을 사용합니다. Web Worker에서 WebAssembly로 실행하며 API 사용료가 없습니다. 모델·실행 파일 다운로드에는 데이터 사용량이 발생합니다.

긴 파일은 `mediabunny` 1.58.1로 필요한 구간만 읽어 처리합니다. 기본 구간은 60초이며 경계의 말을 인식할 수 있도록 앞뒤 최대 2초를 함께 읽습니다. 결과 시간은 원본 영상 기준으로 되돌리고 겹친 문맥의 중복을 정리합니다. 파일 읽기 캐시는 8MiB로 제한하며, 추론에 전달하는 한 구간의 16kHz 모노 음성 배열은 최대 64초·약 4.1MB입니다. 이는 앱 전체의 메모리 사용량을 뜻하지 않습니다. 모델, 디코더, 원본 채널 버퍼, 브라우저 실행에는 별도 메모리가 필요합니다. 짧은 파일의 호환성 대체 분석은 원본 전체를 해독하므로 5분·100MB 제한을 유지합니다.

각 구간 안에서 긴 디지털 무음도 분리하고 소리가 있는 부분만 모델에 전달합니다. 무음 때문에 대사가 길게 늘어나거나 글자가 반복되는 오인식을 줄이기 위한 처리이며, 배경음과 말소리를 구분하는 화자·음성 활동 인식 모델은 아닙니다. 작은 Whisper 모델의 전사 결과는 여전히 직접 검수해야 합니다.

처음 사용할 때 Hugging Face 및 관련 다운로드 CDN에서 모델을, jsDelivr에서 WASM 실행 파일을 가져옵니다. 브라우저가 허용하면 모델을 캐시하지만 저장 공간 정책이나 캐시 삭제로 다시 다운로드할 수 있습니다. 사이트 글꼴은 Google Fonts에서 가져옵니다. 따라서 미디어를 외부로 보내지 않아도 이러한 정적 자원 요청은 발생하며, 완전한 오프라인 실행을 보장하지 않습니다. 자세한 라이선스는 [제3자 구성 요소 고지](../THIRD_PARTY_NOTICES.md)를 참고하세요.

## 개발과 배포

Node.js 24 환경에서 저장소 루트 기준으로 실행합니다.

```powershell
npm ci
npm run dev:web
```

개발 주소는 `http://127.0.0.1:5174/`입니다. 설치형은 기존 `npm run dev`를 그대로 사용합니다. 웹 빌드와 확인은 다음과 같습니다.

```powershell
npm run verify
npm run preview:web
```

`verify`는 타입 검사·테스트·설치형 빌드·웹 빌드를 실행합니다. 웹 결과물은 `dist-web/`, 미리보기 주소는 `http://127.0.0.1:4174/`입니다. 정적 호스팅에 `dist-web/` 내용을 게시하면 되며 추론 서버나 비밀 키가 필요하지 않습니다. 하위 경로에 게시할 경우 빌드 전에 경로를 지정합니다.

```powershell
$env:GINUNI_WEB_BASE = '/ginuni/'
npm run build:web
Remove-Item Env:GINUNI_WEB_BASE
```

[웹 배포 워크플로](../.github/workflows/web.yml)는 `main`의 관련 파일 변경이나 수동 실행으로 테스트·웹 빌드 후 GitHub Pages에 게시합니다. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다. 워크플로 성공만으로 제출을 마치지 말고 공개 URL에서 샘플 편집·다운로드·모델 로딩을 확인하세요. 설치형 릴리스는 기존 `v*` 태그 워크플로로 별도 배포합니다.

## 검증

`npm run verify` 외에 실제 브라우저 흐름은 `scripts/qa-web.mjs`로 확인합니다. 먼저 `npm run preview:web`를 실행하고, 별도 터미널에서 설치된 Playwright 모듈의 절대 경로를 지정합니다. 기본 브라우저는 Microsoft Edge이며 기존 사용자 프로필을 사용하지 않습니다.

```powershell
$env:GINUNI_PLAYWRIGHT_MODULE = 'C:\path\to\node_modules\playwright\index.mjs'
node scripts/qa-web.mjs
```

Playwright가 현재 프로젝트에서 해석되면 환경 변수를 생략할 수 있습니다. `GINUNI_BROWSER_CHANNEL=chrome`으로 Chrome을 선택하고, `GINUNI_WEB_URL`로 다른 미리보기 주소를 지정할 수 있습니다. 검증 결과와 스크린샷은 Git에서 제외된 `output/playwright/`에 저장합니다.

긴 영상의 실제 AI 검증은 `scripts/qa-web-chunks.mjs`로 실행합니다. 5분·100MiB를 모두 넘고 5분 이후에도 한국어 말소리가 있는 테스트 영상을 지정하세요. 기본 검증 자료는 366초·128,426,776바이트 MP4로, 2·58·121·301·349초에 같은 짧은 한국어 음성을 배치하고 나머지는 무음으로 만들었습니다. 이 인공 자료는 분할·경계·무음 회귀 검사 전용이며 사용자에게 제공하는 실제 영화 샘플과 별개입니다.

```powershell
$env:GINUNI_CHUNK_MEDIA = 'C:\path\to\asr-long-large.mp4'
node scripts/qa-web-chunks.mjs
```

검사는 실제 모델을 실행하며 취소 후 대본 보존, 단일 워커 재사용, 한 번에 전달하는 PCM 길이, 실제 파일 읽기의 크기, 5분 이후 원본 타임코드와 긴 무음의 반복 텍스트를 확인합니다. `Blob.slice()`는 데이터 복사가 없는 뷰이므로 뷰의 크기 대신 실제 스트림 읽기와 `arrayBuffer()` 호출을 측정합니다. 정확도 벤치마크나 최대 3시간 전체의 기기별 부하 시험은 아닙니다.

브라우저 검증에서는 실제 샘플 재생·시점 이동·해설 편집, HWPX/JSON 내보내기, 별도 대사 자료의 SRT 내보내기, 새로고침 후 복원, JSON 새 작업 복원, 미디어 교체 후 되돌리기, 잘못된 SRT의 기존 대본 보존, 390px 모바일 화면을 확인합니다. 영상 메타데이터를 읽는 동안 AI 실행을 차단하고 연속 선택 시 최신 파일만 반영하는 회귀 검사도 포함합니다.

**2026년 9월 19일 로컬 검증:** 전체 테스트 **441개**, 타입 검사, 설치형·웹 빌드와 일반 브라우저 검증을 통과했습니다. Edge에서 실제 366초·128,426,776바이트 MP4를 모델 다운로드부터 분석 완료까지 약 **38.5초**에 처리했습니다. 7개 구간에 워커 하나를 재사용했고, 5분 이후 대사를 포함한 15행의 원본 타임코드를 확인했습니다. 원본 전체 `arrayBuffer()` 호출은 0회, 실제 스트림의 최대 단일 읽기는 2MiB였으며 음성 업로드·HTTP 오류·브라우저 실행 오류가 없었습니다. 취소 후 대본 보존과 긴 무음의 반복 글자·과도한 대사 시간도 검사했습니다. 공개 URL 재확인은 배포 후 진행합니다.

**이전 공개 버전의 검증 기록:** 2026년 9월 19일 첫 버전은 로컬과 공개 URL 양쪽에서 편집·내보내기·복원 브라우저 검증을 통과했습니다. 별도 Edge 프로필에서 공개 URL에 한국어 WAV(388KB)를 선택해 실제 모델 다운로드와 전사를 실행했고, 약 13.7초에 타임코드가 있는 대사 3행을 얻었습니다. 네트워크 요청 45건은 모두 GET이었고 음성 업로드, HTTP 오류, 실행 오류는 없었습니다. 작은 모델의 한국어 전사 오류도 확인했으므로 작가의 내용·시간 검수가 필요합니다. 이 확인은 최신 분할 분석의 검증이나 모든 코덱·기기의 지원, 납품 품질을 보장하는 평가는 아닙니다.
