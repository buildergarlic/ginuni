# GiNuNi v0.6.0-beta.3 · Atelier 파일럿 베타

기존 GiNuNi의 업데이트입니다. 새 프로그램이 아니며 기존 프로젝트 저장 위치와 파일 형식을 그대로 사용합니다.

## 달라진 화면

- **새 기누니 로고·아이콘**: 제공된 원본의 흰 배경과 비율을 유지했습니다. 시작 화면과 About, 앱 창과 Windows 실행 파일, 설치·제거 프로그램에 적용합니다.
- **영상 왼쪽, 대본 오른쪽**: 밝고 차분한 Atelier 화면으로 검수에 집중할 수 있습니다. 작은 창과 큰 글씨에서도 선택한 줄의 본문을 볼 수 있도록 이동합니다.
- **한 줄씩 확인**: `확인 완료 · 다음`은 저장에 성공한 뒤 현재 줄을 확인 처리하고 다음 미확인 줄로 이동합니다. `다음 확인할 행`은 이동만 합니다. 저장 오류가 나면 작성 중인 초안과 선택을 유지합니다.
- **도구는 필요할 때**: AI 교정·분석 기록·복구본·설정은 `작업 도구`, 문서와 자막 출력은 `대본 내보내기`에 모았습니다.
- **영상 클릭 이동 유지**: 대사·해설을 누르면 로컬/유튜브 영상이 해당 시각으로 이동합니다. 일시정지 상태와 작성 중인 내용은 유지합니다.
- **새 화면 사용법**: 앱의 `사용법`과 저장소 안내서를 새 메뉴 위치에 맞췄습니다.

## 기존 사용자 업데이트

1. 작업 중인 내용을 저장하고 프로젝트 폴더와 원본 영상을 별도로 백업하세요.
2. 기존 베타 앱의 `About GiNuNi`에서 업데이트를 확인하거나 아래 설치 파일을 실행하세요. 검수 화면에서는 `작업 도구`에서 About을 열 수 있습니다.
3. 시험용 프로젝트에서 영상 재생·대본 수정·HWPX/SRT 내보내기를 먼저 확인하세요.

[Windows 10/11 x64 설치 파일](https://github.com/buildergarlic/ginuni/releases/download/v0.6.0-beta.3/ScreenDescriptionScriptMaker-0.6.0-beta.3-Setup.exe)

앱 ID, 제품명 `화면해설 대본 도구`, 설치 바로가기 이름은 업데이트 호환성을 위해 유지합니다. 문서 폴더의 `화면해설 대본 도구/Projects`도 바뀌지 않습니다. 이 호환 설계가 모든 PC에서의 설치·데이터 보존 실증을 뜻하지는 않습니다.

## 파일럿 범위와 주의사항

이 버전은 소유자가 승인한 **파일럿 베타**이며 정식 1.0이나 납품 적합 판정이 아닙니다. 중요한 납품에는 사용하지 말고 백업이 있는 시험 자료로 먼저 확인하세요.

아직 별도 검증이 필요한 항목:

- 실제 화면해설작가의 첫 사용·장시간 검수·오류 복구
- 실제 한국어 방송의 전사·화자·시간 정확도와 실제 OpenAI 계정 연결
- 한컴오피스에서 긴 HWPX의 페이지 나눔·서식·복구 경고
- 깨끗한 Windows 10/11에서 설치·제거·업데이트 후 데이터 보존, 화면 배율과 Windows 내레이터

자동 테스트와 합성 자료 검사는 위 현장 시험을 대신하지 않습니다.

코드 서명 인증서가 없는 배포는 **무서명 파일럿**입니다. Windows SmartScreen에서 알 수 없는 게시자 경고가 나타날 수 있습니다. 공식 `buildergarlic/ginuni` Releases 출처와 함께 게시된 `SHA256SUMS.txt`를 확인하세요. 실제 서명 상태는 해당 태그의 Windows release 검사 결과를 확인하세요.

## 검증 기록

태그 전 전체 검사·분리된 테스트 프로필의 실제 Electron 동작 검사·Windows 설치본 생성 결과는 [beta.3 배포 검증 기록](https://github.com/buildergarlic/ginuni/blob/v0.6.0-beta.3/docs/design/2026-09-10-beta3-release-verification.md)에 기록합니다. GitHub Actions가 동일한 태그에서 다시 검사하고 설치 파일·블록맵·업데이트 정보·SHA-256을 게시합니다.
