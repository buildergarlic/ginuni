# GiNuNi v0.6.0-beta.2 · 파일럿 베타 업데이트

기존 GiNuNi의 업데이트입니다. 프로젝트 형식은 바꾸지 않았습니다. 별도의 새 프로그램이 아니며, 실제 작가 검증을 완료한 정식판도 아닙니다.

## 달라진 점

- **사용법이 쉬워졌습니다.** 앱 왼쪽 `사용법`에서 큰 글씨의 3단계 안내와 클릭 이동 연습 그림을 볼 수 있습니다. 목차로 필요한 설명을 찾아가고, 교정·복구·문제 해결은 펼쳐 볼 수 있습니다.
- **업데이트 기능을 설명합니다.** 행의 확인 완료, 수정 후 재확인, AI 교정 제안 적용·거절, 이전 상태 복구, HWPX/SRT 저장 차이를 실제 버튼 이름으로 안내합니다. 유료·외부 전송 기능은 따로 표시합니다.
- **유튜브 자동 제목의 큰따옴표를 정리합니다.** `오늘의 “특별한” 이야기`는 프로젝트 제목에서 `오늘의 특별한 이야기`로 표시합니다. 원본 영상 제목 정보는 유지됩니다. 기존에 저장한 제목을 일괄 변경하지 않습니다.
- **Threads 주소를 수정했습니다.** About GiNuNi에서 [@buildergarlic](https://www.threads.com/@buildergarlic)으로 연결됩니다.

기존 대사·해설 클릭 이동, 편집 중 내용 보존, 검증 가능한 AI 작업 흐름은 그대로 제공합니다. 화면해설은 작가가 직접 작성하며, AI가 자동 생성하거나 확인 완료하지 않습니다.

## 설치 전 확인

1. 기존 프로젝트와 원본 영상을 별도로 백업하고 시험용 프로젝트부터 확인하세요.
2. About GiNuNi의 `업데이트 확인`을 이용하거나 이 릴리스의 `ScreenDescriptionScriptMaker-0.6.0-beta.2-Setup.exe`를 받으세요. 내려받기가 끝나면 `재시작하여 업데이트`로 교체합니다.
3. 이 파일럿은 코드 서명 인증서가 없는 경우 **무서명**으로 배포됩니다. Windows SmartScreen에 알 수 없는 게시자 경고가 나타날 수 있습니다. 공식 `buildergarlic/ginuni` Releases와 함께 제공하는 `SHA256SUMS.txt`로 출처·파일을 확인하세요.
4. 이전 v0.5 프로젝트의 대사와 해설은 유지되지만 확인 기록은 새 방식에 맞춰 확인 전으로 표시될 수 있습니다.

## 검증 범위와 남은 확인

배포 전 자동 테스트 226개(29개 파일), 타입 검사와 빌드가 통과했습니다. 실제 Electron에서 설명서·Threads 점검 5개, 기존 대본 작업 흐름 점검 8개, 유튜브 메시지 경계 점검 4개가 통과했습니다. 설명서 점검에는 실제 목차 스크롤, 클릭 연습, 키보드로 질문 펼치기, Threads 외부 링크, 1440·1100px 화면 배치가 포함됩니다. 이번 유튜브 검사는 통제된 메시지 경계 검사이며 실제 유튜브 재생 검사를 새로 했다는 뜻은 아닙니다. 검증 실행 방법은 아래와 같습니다.

```powershell
npm ci
npm run verify
node scripts/qa-guide.mjs
node scripts/qa-workflow.mjs
```

Electron 점검은 별도 프로필과 합성 자료를 사용합니다. Playwright가 별도 설치 경로에 있으면 `GINUNI_PLAYWRIGHT_MODULE`로 `playwright/index.mjs` 경로를 지정합니다. 실제 사용자 자료나 API 키를 이용한 유료 분석은 하지 않습니다.

실제 화면해설작가의 사용성, 실제 한국어 방송 자료 정확도, 실제 OpenAI 계정 연결, 한컴오피스 긴 문서 서식·페이지 나눔, 깨끗한 Windows 10/11 설치·제거 및 설치 후 데이터 보존 검증은 별도로 필요합니다. 자동 검사 통과는 이 현장 검증을 대신하지 않습니다. 중요한 납품에는 사용하지 말고 시험용 자료로 먼저 확인하세요.

`npm audit --omit=dev` 기준 런타임 의존성 취약점은 0건입니다. 기존 개발용 의존성의 moderate 경고 2건은 남아 있으며, 개발용 검사와 설치본 런타임 검사는 구분합니다.
