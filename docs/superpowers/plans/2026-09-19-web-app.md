# GiNuNi 웹앱 구현 계획

**목표:** Windows 앱과 병행 가능한 공개 웹 작업실을 제공한다.
**설계:** [웹앱 설계](../specs/2026-09-19-web-app-design.md)
**구조:** 독립 Vite/React 진입점 + 공유 문서 로직 + 브라우저 저장 및 Worker 음성 분석.

1. 문서 코어: HWPX XML과 SRT 파서를 공유 모듈로 추출하고 기존 데스크톱 경로를 재연결. 브라우저 ZIP 생성 및 회귀 테스트.
2. 프로젝트: 검증된 JSON 백업·복구, 자동 저장 오류 처리, SRT 가져오기, 원본 연습 대본. 손상 파일/저장 한도/겹침 테스트.
3. AI: 브라우저 오디오 디코딩, 길이 제한, 모델 다운로드, Worker 실행, 취소, 타임스탬프 검증.
4. UI: 홈/최근 작업, 영상·대본 작업실, 해설/대사 편집, 검수 진행, 가져오기/내보내기, 개인정보·사용법 안내, 모바일 대응.
5. 검증/배포: 타입·전체 테스트·설치형/웹 빌드, 브라우저 주요 흐름 확인, 공개 Pages 배포와 URL 확인.

입력 오류나 AI 실패는 기존 대본을 바꾸지 않는다. 새 결과 적용 전 기존 행이 있으면 대체 여부를 확인한다. 저장 실패를 성공으로 표시하지 않는다. 자동 생성한 해설 후보는 실제 무음이나 AI가 작성한 해설로 표현하지 않는다.
