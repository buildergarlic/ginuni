# GiNuNi 웹 작업실

대회 심사위원과 일반 사용자가 설치 파일 없이 공개 URL에서 핵심 기능을 체험하도록 한다. 기존 Windows 배포와 같은 저장소에서 독립된 Vite 웹 타깃을 관리한다. 사용자는 무료 브라우저 AI 분석을 선택했다.

- React 웹 작업실: 샘플 장면 카드와 예시 대본, 새 프로젝트, 로컬 영상 재생, SRT 가져오기, 직접 입력, 해설 후보, 시간 탐색, 검수, HWPX/SRT/JSON 다운로드.
- 공유 로직: 자막 파싱, 대사/해설 모델, 타임코드, HWPX XML 및 SRT 직렬화. Electron 파일 처리 경계는 유지한다.
- 개인정보: 로컬 영상은 Object URL로 재생한다. 대본은 이 브라우저 localStorage에 저장하고 JSON으로 백업한다. 미디어는 저장하지 않아 다시 열 때 재선택이 필요하다. 클라우드 저장·로그인 없음.
- AI: Transformers.js 3.8.1, 다국어 Whisper tiny q8, 격리 Worker, 한국어 전사, 최대 100MB/5분, 취소 가능. 모델 최초 다운로드와 장치별 속도/정확도 한계를 표시. 화자 자동 분리 및 화면 내용 자동 묘사는 제공하지 않는다.
- 배포: GitHub Pages의 정적 HTTPS 사이트. 사이트는 설치 파일 다운로드를 유도하지 않는다. 대회 공개 유지 기간은 2026-09-21~2026-10-17이다.
- 검증: 기존 앱 회귀 테스트/타입/빌드, 웹 프로젝트 입력·저장·자막·내보내기 테스트, 브라우저에서 샘플 편집/새로고침/파일 다운로드 및 반응형 확인. 실제 AI 실행은 별도 확인하며 테스트 대역과 구분한다.
