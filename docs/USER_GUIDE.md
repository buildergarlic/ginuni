# 사용자 안내서

## 1. 분석 방식 선택

### 내 PC에서 분석 — 기본값

API 키와 사용료 없이 동작합니다. 처음 분석할 때 약 181MB의 한국어 지원 모델을 자동으로 받습니다. **설정 → 로컬 모델 다운로드**에서 미리 받을 수도 있습니다. 한 번 설치하면 인터넷이 끊겨도 로컬 영상 전사가 가능합니다.

영상 음성은 외부 서버로 전송되지 않습니다. 로컬 첫 버전은 자동 화자 분리를 하지 않으므로 근거 없는 화자명을 붙이지 않고 대사 내용만 표시합니다.

### OpenAI로 분석 — 선택 사항

앱의 **설정**을 열고 본인이 만든 OpenAI API 키를 입력한 뒤 **키 저장**을 누릅니다. 키를 다른 사람에게 보내거나 프로젝트 폴더에 적어두지 마세요.

## 2. 프로젝트 만들기

### 내 컴퓨터 파일

**동영상 또는 음성 파일 선택**에서 MP4, MKV, MOV, AVI, WEBM, M4A, MP3, WAV 등의 파일을 선택합니다. 원본 파일은 복사되지 않으므로 검수가 끝날 때까지 이동하거나 삭제하지 마세요.

### 유튜브 링크

본인이 처리할 권한이 있는 공개·일부공개 URL만 입력합니다. 비공개, 로그인 필요, DRM, 실시간 방송은 지원하지 않습니다. 검수할 때 영상 재생을 위해 인터넷 연결이 필요합니다.

## 3. 음성 분석

프로젝트 화면 오른쪽 아래의 **음성 분석 시작**을 누릅니다. 다음 단계가 자동으로 진행됩니다.

1. 영상 길이 확인
2. 전사용 음성 변환
3. 선택한 방식으로 로컬 음성 분석 또는 OpenAI 음성·화자 분석
4. 대사 및 2초 이상 무음 구간 구성
5. 프로젝트 자동 저장

중간에 취소해도 프로젝트는 남아 있으며 다시 시작할 수 있습니다.

## 4. 검수

- 표의 행을 누르면 해당 시작 시점으로 이동합니다.
- **현재 위치를 시작으로/종료로** 버튼으로 재생 위치를 타임코드에 반영합니다.
- 대사 내용을 직접 수정하고 `화자1`을 실제 이름으로 전체 변경할 수 있습니다.
- 긴 행은 현재 위치에서 나누고, 불필요하게 나뉜 행은 다음 행과 합칠 수 있습니다.
- 해설 후보가 잘못 잡히면 대사로 바꾸거나 행을 삭제합니다.
- 시간 겹침이 있으면 HWPX 내보내기가 비활성화됩니다.

AI가 배경 음악의 노랫말이나 겹쳐 말한 음성을 잘못 인식할 수 있습니다. 납품 전에는 모든 행을 영상과 대조하세요.

크기가 큰 MP4도 행을 누르면 해당 구간만 불러오도록 설계되어 있습니다. 재생 화면이 계속 검정으로 멈추면 원본 파일이 이동되었는지 확인한 뒤 최신 버전으로 업데이트하세요.

## 5. HWPX 저장

**HWPX 내보내기**를 누르고 저장 폴더를 선택합니다. 파일명은 다음 규칙을 사용합니다.

`작품명_화면해설대본_V01.hwpx`

같은 파일이 있으면 `V02`, `V03`으로 증가하며 기존 파일을 덮어쓰지 않습니다.

## 5-1. SRT 저장

**SRT 내보내기**를 누르고 저장 폴더를 선택합니다. HWPX와 동일하게 버전이 증가하고, 대사 행(`대사`)만 저장됩니다.

파일명 규칙:

`작품명_화면해설대본_V01.srt`

## 6. 파일을 잃지 않는 방법

- 소스 코드: `C:\GiNuNi\screen-description-script-maker`
- 사용자 프로젝트: Windows 문서 폴더의 `화면해설 대본 도구\Projects`
- 설치본: 소스 코드 폴더의 `release`
- 완성 HWPX: 내보낼 때 사용자가 선택한 폴더
- 완성 SRT: 내보낼 때 사용자가 선택한 폴더

최근 프로젝트는 앱 첫 화면에서 다시 열 수 있습니다. 프로젝트 삭제를 누르면 프로젝트 JSON과 내려받은 유튜브 음성이 함께 삭제되므로 필요한 HWPX를 먼저 확인하세요.

## 오류 해결

- **API 키가 올바르지 않습니다**: 설정에서 키를 삭제하고 다시 저장합니다.
- **로컬 모델 다운로드 실패**: 인터넷 연결을 확인하고 설정에서 다시 다운로드합니다. 모델이 손상된 경우 `로컬 모델 복구`를 누릅니다. 설치 후에는 인터넷이 필요 없습니다.
- **로컬 분석 오류**: 검수 화면의 오류 배너에서 실패 단계와 해결 방법을 확인합니다. `다시 분석`을 먼저 시도하고, 계속 실패하면 `진단 파일 저장`으로 저장한 JSON을 문의 시 첨부합니다. 진단 파일에는 음성·대사·API 키가 포함되지 않습니다.
- **실행 파일 차단 또는 아키텍처 비호환**: Windows 보안 프로그램이 `ffmpeg`, `ffprobe`, `whisper-cli` 실행을 차단했는지 확인합니다. ARM64 PC에서는 x64 호환 실행이 가능한 경우에만 로컬 모드를 사용할 수 있습니다.
- **메모리 부족**: 다른 프로그램을 종료하고 다시 시도합니다. 긴 영상은 OpenAI 모드 또는 더 여유 있는 PC에서 처리할 수 있습니다.
- **로컬 분석이 느림**: CPU 성능과 영상 길이에 따라 실제 재생 시간보다 오래 걸릴 수 있습니다. 중간에 취소하고 OpenAI 모드로 바꿀 수 있습니다.
- **OpenAI 크레딧이 없습니다 / 지출 한도에 도달했습니다**: OpenAI Platform의 API 결제·프로젝트 한도를 확인합니다. ChatGPT 구독과 API 사용료는 별도입니다.
- **OpenAI 요청 속도 제한**: 잠시 후 다시 시도합니다.
- **OpenAI 권한·모델 오류**: 앱에 표시된 오류 코드와 요청 ID를 함께 오류 제보에 남깁니다. API 키 값은 절대 공유하지 마세요.
- **OpenAI HTTP 400**: 검수 화면에서 OpenAI 오류 코드, 문제 파라미터, 정제된 서버 안내를 확인합니다. 오디오 형식 오류이면 `오디오 형식 변환 후 재시도`를 누릅니다. `response_format` 또는 모델 오류라면 화자 분리 모델 접근 권한과 앱 버전을 확인한 뒤 요청 ID를 문의에 남깁니다.
- **OpenAI 음성 파일 크기 초과**: 전송 전 25MB 제한을 검사합니다. 제한을 넘으면 더 짧은 영상으로 나누거나 다른 영상을 사용해야 합니다.
- **24.5MB 초과**: 영상 길이 또는 오디오 특성이 첫 버전의 처리 범위를 벗어났습니다.
- **유튜브 다운로드 실패**: URL 공개 상태와 인터넷 연결을 확인하고 최신 앱으로 업데이트합니다.
- **원본을 재생할 수 없음**: 로컬 원본이 이동되었는지 확인합니다. 큰 MP4의 중간·끝 이동은 v0.3.0-beta.1 이상, 유튜브 플레이어 오류 153은 v0.3.0-beta.2 이상에서 수정되었습니다.
