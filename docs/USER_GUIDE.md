# GiNuNi 사용법

v0.6.0-beta.3 · 화면해설작가를 위한 파일럿 안내서

**대사 정리는 함께, 화면해설은 작가님의 손으로.**

앱 첫 화면 왼쪽 **사용법** 메뉴에서 큰 글씨와 연습 그림으로 같은 과정을 따라 할 수 있습니다. 대본 작업 중에는 **내 프로젝트**를 눌러 첫 화면으로 돌아갑니다. 이 문서는 보관·공유용 설명입니다. 먼저 짧은 시험 영상으로 연습하고 중요한 대본은 따로 백업하세요. 실제 작가 사용성·방송 자료 정확도·한컴오피스 긴 문서 검증은 아직 별도로 필요합니다.

## 한눈에 보는 세 걸음

| ① 영상 넣기 | ② 듣고 쓰기 | ③ 확인하고 저장 |
|---|---|---|
| 파일 또는 유튜브 링크 선택 | 대사 초안을 원음과 비교 | 확인 완료 · 다음 |
| 사용 권리 확인 → 프로젝트 만들기 | 해설은 작가가 직접 작성 | HWPX 또는 SRT 내보내기 |

## 1. 첫 프로젝트를 만들어요

1. **새 프로젝트 만들기**를 누릅니다.
2. **내 컴퓨터 파일**에서 동영상·음성 파일을 선택하거나, **유튜브 링크**에 주소를 붙여 넣습니다.
3. 사용할 권리가 있는 영상인지 확인하고 동의 항목을 체크합니다.
4. **프로젝트 만들기**를 누릅니다.
5. 프로젝트 화면의 **로컬 음성 분석 시작**을 누릅니다.

기본은 **내 PC에서 분석**입니다. API 키와 사용료가 없고 음성을 외부 분석 서버로 보내지 않습니다. 첫 사용에는 약 181MB 분석 모델을 한 번 내려받으므로 인터넷이 필요합니다. 설정에서 미리 내려받을 수도 있습니다. 모델 준비 후 로컬 파일 분석에는 인터넷이 필요하지 않습니다.

- 영상은 **3시간 이하**로 준비하세요.
- 로컬 원본 영상은 복사되지 않습니다. 작업 중 이동하거나 삭제하지 마세요.
- 유튜브는 사용 권한이 있는 공개·일부공개 영상만 지원합니다. 비공개·로그인 필요·DRM·실시간 방송은 지원하지 않습니다.
- 유튜브 재생·음성 내려받기에는 인터넷이 필요합니다. 내 PC 분석 선택과 유튜브 접속은 별개입니다.
- 유튜브 프로젝트 제목을 비우면 분석 준비 중 영상 제목을 가져옵니다. 프로젝트 제목에서는 일반·굽은 큰따옴표를 제거합니다. 예: 오늘의 “특별한” 이야기 → 오늘의 특별한 이야기. 기존 프로젝트 제목을 일괄 변경하지는 않습니다.

## 2. 오른쪽 문장을 누르면 그 장면으로!

왼쪽에서 영상을 보고, 오른쪽 **대본 쓰기**에서 대사와 해설을 고칩니다. 화면 위 **작업 도구**에는 원문, 자동 점검 알림, 교정 제안, 행 편집, 이전 저장본과 작업 기록이 있습니다. 화자 이름 변경은 화자 표시가 있는 대본에서 사용할 수 있습니다. **설정**과 **About GiNuNi**도 여기서 엽니다. 영상 아래 **원문과 작업 기록**을 눌러도 같은 도구가 열립니다.

대사·해설 행 또는 현재 편집 중인 내용 칸을 클릭하면 해당 행의 **시작 시각**으로 이동합니다. 유튜브와 로컬 영상에서 사용할 수 있습니다.

- 작성 중인 글은 유지됩니다.
- 일시정지 중이면 이동 후에도 일시정지 상태입니다. 재생은 직접 눌러 주세요.
- **대본 쓰기** 위쪽의 **글자 크기**에서 **+**, **−** 또는 막대를 움직여 더 편하게 읽을 수 있습니다.
- 대사는 실제로 들리는 말과 대조해 고칩니다. 화자 표시가 있다면 이름도 확인합니다.
- 기본 내 PC 분석은 화자를 자동으로 나누지 않습니다.

**해설은 작가가 직접 씁니다.** AI는 화면해설을 자동으로 쓰거나 정확성을 보증하지 않습니다. 해설 후보 구간에도 음악·효과음·놓친 대사가 있을 수 있으니, 실제로 해설을 넣어도 되는지 원음을 확인하세요.

방금 적용한 편집을 한 단계 되돌리려면 대본 아래 **실행 취소**를 누릅니다. 되돌릴 편집이 있을 때 버튼을 사용할 수 있습니다. 이전 저장본을 불러오는 방법은 아래 6번을 보세요.

### 시간과 행 편집

행을 선택하고 표에서 시작·종료를 수정합니다. 1분 23초는 **01:23**입니다. **작업 도구 → 선택한 행 편집**에서 **현재 위치를 시작으로**, **현재 위치를 종료로**를 누르면 재생 위치를 반영합니다.

시작은 종료보다 빨라야 하고 이웃 행과 시간이 겹치지 않아야 합니다. 행의 우클릭 메뉴에서 나누기·합치기·종류 변경·삭제를 이용합니다. 나누기 전 재생 위치가 선택한 행 안에 있는지 확인하세요.

## 3. 확인 완료는 따로 표시해요

**다음 확인할 행 → 영상과 대본 대조 → 확인 완료 · 다음**

대본 아래 **확인 완료 · 다음**은 현재 행의 수정 내용을 저장하고 그 행을 확인 완료로 표시한 뒤, 아직 확인하지 않은 다음 행으로 이동합니다. 다음 행까지 확인 완료가 되는 것은 아닙니다. 남은 행이 없으면 **모든 행을 확인했어요**라고 표시됩니다.

**다음 확인할 행**은 아직 확인하지 않은 행으로 이동하는 버튼입니다. 현재 행에 확인 완료 표시를 남기지 않으므로, 나중에 확인할 곳으로 넘어갈 때 사용하세요.

문장을 고쳤다고 확인 완료가 되지는 않습니다. 확인 완료한 행도 다시 수정하면 확인 전으로 바뀝니다. 수정한 내용을 다시 살펴보라는 표시입니다.

이전 v0.5 프로젝트는 새 확인 방식으로 옮기며 확인 전으로 표시될 수 있습니다. 대사·해설이 사라진 것이 아닙니다. 영상을 확인한 뒤 다시 표시하세요.

## 4. 저장: 작업 이어 쓰기와 전달하기는 달라요

편집 후 **자동 저장됨** 표시를 확인합니다. 작업은 **최근 프로젝트**에서 다시 열 수 있습니다. 유효하지 않은 시간을 입력 중이면 저장 대기 상태일 수 있으니 입력을 마무리하세요.

다른 사람에게 전달할 파일은 따로 내보냅니다.

| 필요한 결과 | 누를 버튼 | 포함되는 내용 |
|---|---|---|
| 한컴오피스용 화면해설 대본 | 대본 내보내기 → HWPX 내보내기 | 대사와 해설 |
| 대사 자막 | 대본 내보내기 → SRT 내보내기 | 대사 행만, 해설 제외 |

화면 위 **대본 내보내기**에서 파일 형식을 고르고 저장 폴더를 선택하세요. 같은 제목의 파일이 있으면 **V01 → V02 → V03**처럼 새 파일을 만들어 기존 출력 파일을 덮어쓰지 않습니다.

시간·내용 오류는 먼저 고쳐야 합니다. 확인 전 행이 남았다면 검수를 계속하거나 경고를 확인하고 현재 내용을 작업용 파일로 저장할 수 있습니다. 작업용 파일을 최종 검수본으로 취급하지 마세요.

HWPX는 한컴오피스에서 문장·서식·긴 문서의 페이지 나눔을 직접 확인합니다.

## 5. 필요할 때만: 대사 교정 제안

**선택 기능 / 유료 / 선택한 대사 텍스트를 OpenAI로 전송**

1. **작업 도구 → 설정**에서 OpenAI API 키를 저장한 뒤 **돌아가기**를 누릅니다. 키를 다른 사람에게 공유하지 마세요.
2. **작업 도구 → 사용 권리와 외부 전송 설정**에서 대사 텍스트 전송 동의를 체크하고 **동의 설정 저장**을 누릅니다. 음성 전송 동의와 별개입니다.
3. 도구를 닫고 대사 한 행을 선택합니다. 다시 **작업 도구 → 선택한 대사 교정 제안 받기 · 선택 사항**을 열고 **선택한 대사 교정 요청 (유료)**를 누릅니다.
4. **수정 전·제안·이유**를 원음과 비교합니다.
5. **제안 적용** 또는 **제안 거절**을 선택합니다.

AI 제안으로 뜻이 달라질 수 있습니다. 적용 후에는 다시 확인해야 합니다. 교정 요청은 화면해설을 생성하거나 시간을 바꾸는 기능이 아닙니다.

## 6. 이전 대본으로 돌아가기

**작업 도구 → 이전 상태로 복구 → 이전 저장 목록 보기 → 복구할 저장본 선택 → 선택한 저장본으로 복구**

주요 작업 전에 남기는 최근 10개 복구본을 제공합니다. 모든 타이핑 순간을 보관하는 것은 아닙니다. 복구 직전 내용도 저장본으로 남습니다. 영상까지 복제하는 기능은 아니므로 별도의 파일 백업이 필요합니다.

## 7. 다른 분석 방식과 기록 보기

프로젝트를 만들 때 **고급 옵션 · 음성 분석 방식 변경**에서 선택합니다. 프로젝트를 만든 뒤 분석을 시작하기 전에는 **로컬 음성 분석 시작** 옆 **고급 분석 옵션**에서 바꿀 수 있습니다.

| 분석 방식 | 특징 |
|---|---|
| 내 PC에서 분석 | 기본값. 대사 초안. 음성 외부 전송·API 사용료 없음 |
| 내 PC + 화자 분리 | 실험 기능. 목소리 구분. 잘못 나뉜 화자는 직접 확인 |
| OpenAI로 분석 | API 키, 음성 외부 전송 동의, API 사용료 필요 |

**작업 도구 → 선택한 행의 원래 음성 인식 결과**에서 초안을 비교합니다. 같은 도구의 **작업 기록 · 고급 정보**에서는 분석·수정·확인 기록을 볼 수 있습니다. 작업 기록 파일에는 대본 내용이 포함될 수 있으므로 공유 전 확인하세요. 문의용 진단 파일과는 다릅니다.

## 8. 막혔을 때

| 상황 | 해 볼 일 |
|---|---|
| 내보내기 버튼을 누를 수 없어요 | 대본 위 시간 오류 또는 작업 도구의 자동 점검 알림에서 해당 행으로 이동해 시간 역전·겹침·빈 내용을 수정하세요. |
| 유튜브가 안 나와요 | 인터넷·공개 상태·외부 재생 허용 여부를 확인하세요. 권한 있는 원본 파일이 있다면 새 로컬 프로젝트로 작업할 수 있습니다. |
| 클릭해도 재생되지 않아요 | 일시정지 중이면 시각만 이동하는 것이 정상입니다. 재생 버튼을 직접 누르세요. |
| 분석이 실패했어요 | 표시된 해결 방법을 확인하세요. 모델 손상 안내는 로컬 모델 복구를 이용하고, 반복되면 진단 파일 저장으로 문의하세요. |
| 이전 프로젝트가 확인 전이에요 | 확인 방식이 바뀐 것입니다. 대사·해설을 원음과 대조하고 확인 완료 · 다음을 눌러 주세요. |
| 원본을 재생할 수 없어요 | 원본 파일이 이동·삭제되지 않았는지 확인하세요. |

API 키·원본 영상·대본을 문의에 함께 보내지 마세요. 외부 분석을 다시 요청하면 추가 비용이 발생할 수 있습니다.

## 9. 파일 위치와 업데이트

- 프로젝트: **Windows 문서 폴더 → 화면해설 대본 도구 → Projects**. 정확한 위치는 앱 설정에서 확인합니다.
- HWPX·SRT: 내보낼 때 선택한 폴더.
- 원본 영상: 처음 선택한 위치. 별도로 보관합니다.

프로젝트를 삭제하면 프로젝트 내용과 내려받은 음성도 사라질 수 있습니다. 필요한 자료를 백업한 뒤 삭제하세요.

첫 화면의 **About GiNuNi → 업데이트 확인**에서 새 버전을 확인합니다. 대본 작업 중에는 **작업 도구 → About GiNuNi**로 엽니다. 내려받기가 끝나면 **재시작하여 업데이트**를 누릅니다. 업데이트 전 프로젝트와 원본 영상을 별도로 백업하세요.

이 파일럿은 무서명 설치본일 수 있어 Windows 경고가 나타날 수 있습니다. 반드시 [공식 GitHub Releases](https://github.com/buildergarlic/ginuni/releases) 출처와 SHA-256을 확인하세요.
